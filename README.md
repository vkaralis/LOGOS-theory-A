# LOGOS Theory A — Mathematical Foundations of Recovery-Gated Treatment

## From Dynamical Systems to Model-Informed Clinical Decisions

LOGOS (Longitudinal Optimization of Global Outcomes and Strategies) is a mathematical framework for evaluating whole-regimen treatment strategies through mechanistic pharmacokinetic/pharmacodynamic (PK/PD) modeling, dynamical systems, and constrained optimization.

Theory A investigates the mathematical conditions under which treatment interruption, biological recovery, and state-dependent restart can improve therapeutic objectives or restore treatment feasibility.

The framework integrates:

- **Dynamical systems:** Coupled models of drug exposure, treatment responsiveness, tissue injury, and disease progression.
- **Mathematical analysis:** Analytical bounds, no-gain theorems, and conditional recovery-window results.
- **Constrained optimization:** Quantitative comparisons of continuous and intermittent treatment strategies under matched resource and safety constraints.
- **Adaptive decision theory:** State-dependent restart conditions and the value of imperfect biological information.
- **Clinical pharmacology:** Model-based investigation of treatment interruptions, hematological toxicity, and recovery-related decision variables.

The accompanying Python implementations provide reproducible simulations, numerical experiments, sensitivity analyses, and independent verification of the theoretical results.

**Scientific objective:** To establish when biological recovery creates mathematically demonstrable value for treatment scheduling and how that value may inform future model-based clinical decision-making.

The results are conditional on specified mathematical models and do not establish a clinically validated restart policy.

Version **0.5.0** implements exposure-gated responsiveness recovery, injury repair,
cyclic dosing, finite follow-up, constant-family comparisons and conditional restart
information calculations. All uploaded observation-like records are synthetic.
The normalized models are hypotheses; the results do not define clinical dosing rules.

## Reproduce in a clean environment

Supported Python: **3.12 only** (`>=3.12,<3.13`). Package metadata, CI and these
commands use the same supported minor version. Wider support can be added after testing.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m pip install --no-build-isolation --no-deps .
python -m unittest discover -s tests -v
python scripts/verify_manifest.py
logos-reproduce --output results
python scripts/verify_outputs.py results
```

On Windows activate with `.venv\Scripts\activate`. `python -m
logos_recovery.pipeline --output results` is equivalent to `logos-reproduce`.
Full execution regenerates all model tables, PNG/SVG/PDF figures, numerical
extension checks, synthetic demonstrations and the actual environment record.
A shorter cross-solver run is `logos-reproduce --verify-only --output checks`;
this does not execute the full search or constant-family bounds.

## Contents

- `src/logos_recovery/models.py`: analytic PK, affine periodic states, independent
  continuous ODE verification, 1,395-cycle screening, controls, amplitude bounds,
  phase classification, common-start finite comparison and palbociclib safety illustration.
- `extensions.py`: stationary constant-family upper bound, all 32 deterministic
  parameter-box cases and noisy recovery-rate information.
- `finite_bounds.py`: common-initial-state constant-family upper bound with independent solvers.
- `presentation.py`: distinct frozen candidate identities and figures of recovery and restart.
- `restart.py`: constrained drug-free waits, including degenerate cases.
- `synthetic.py`: seeded toy panel and subject-held-out prediction example.
- `data/`: synthetic panel, generation metadata and deterministic simulation benchmarks.
- `docs/`: model equations, numerical evidence, data provenance, topics and release instructions.
- `reference_results/`: numerical tables, benchmarks and recorded validation from the supplied full execution. Figures are regenerated by the pipeline; duplicate synthetic outputs are omitted.

The four candidate identities A-PER-REFINED, A-PER-RERUN, A-AMP-5 and A-CAP-EXT
retain different periods and periodic initial states. Rounded equality does not
make their controls identical. The fresh optimizer result is reported separately.
Exact-mean-dose comparisons and common-cap comparisons retain separate resource
rules; common caps permit different realized amounts.

## Scientific scope and data

See [model definitions](docs/MODELS.md) and [data provenance](data/README.md).
The palbociclib illustration uses the published typical-parameter structure of
[Le Marouille et al., Pharmaceutics 2021](https://doi.org/10.3390/pharmaceutics13101708).
It includes no tumor endpoint, new fitting or individual variability.

Periodic injury peaks use endpoints, switches and bracketed derivative roots.
Phase-map safety is sampled. Optimizer candidates are not global optima, and
conservative derivative-grid bounds are not interval-arithmetic certificates.
The synthetic ANC example demonstrates software behavior only and cannot
reproduce or validate observed-data findings.
